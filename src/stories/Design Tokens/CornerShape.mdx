## Tokens CSS

```scss
--ui-corner-shape-round
--ui-corner-shape-squircle
--ui-corner-shape-scoop
--ui-corner-shape-bevel
--ui-corner-shape-notch
```

Tamanhos de raio:

```scss
--ui-radius-sm   // 6px
--ui-radius-md   // 10px
--ui-radius-lg   // 16px
--ui-radius-xl   // 24px
```

---

## Classes utilitárias

```txt
.ui-corner-{shape}-{size}
```

Exemplos: `.ui-corner-squircle-lg`, `.ui-corner-notch-xl`

---

## SCSS mixin

```scss
@include ui-corner-shape(squircle, var(--ui-radius-lg));
```

> Para a matriz completa (5 modelos × 4 tamanhos), abra **Design Tokens / Corner Shape / Matriz completa** no Canvas.
